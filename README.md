## ✨ أبرز الميزات

### 1. الخصوصية والمحلية أولاً (Local-First Architecture)
* **بياناتك على جهازك فقط:** لا خوادم ترفع عليها أسعارك وعملائك، ولا اشتراكات شهرية، ولا تتبع.
* **ربط مجلد مباشر:** تكامل مع متصفحك عبر `File System Access API` لحفظ العروض كملفات JSON مقروءة ومرتبة على جهازك مباشرة.
* **استرداد آلي فوري:** مساحة استرداد مؤقتة مشفرة محلياً تحمي بياناتك من الضياع حتى لو انقطع اتصال إذن المجلد.

### 2. تجربة مستخدم حسية فريدة (Tactile Apple-Style Workspace)
* **مكتب أوراق A4 واقعي:** استعراض عروض الأسعار كأوراق حقيقية تتكيف بأربعة مقاسات (`دقيق`، `صغير`، `متوسط`، `كبير`).
* **طي زاوية الورقة (Paper Corner Curl):** انقر على ركن أي ورقة لتشاهدها تنثني وتنتقل فيزيائياً إلى مستند التحديد العائم.
* **تجميع الورق بالسحب:** اسحب ورقة فوق ورقة لتنفتح كأوراق UNO وتتحول فوراً إلى مجلد مجمع.
* **إسقاط الأوراق داخل المجلدات:** اسحب أوراقك نحو المجلدات لتنزلق بسلاسة واهتزاز هبوط وتحدث العداد تلقائياً (`+1`).
* **سلة نفايات تفاعلية ثلاثية الأبعاد:** عند حذف أي ورقة، تنكمش كورقة مجعدة وتُسدد بفيزياء ارتدادية إلى سلة المهملات.

### 3. محرر عروض احترافي ومعاينة A4 حية
* **تقسيم تلقائي للصفحات (Auto-Pagination):** حساب دقيق لارتفاع الصفحات ومنع تقطيع الجداول أو البنود بين الصفحات.
* **قوالب جاهزة قابلة للتخصيص:** قوالب تجارية، تقنية، إبداعية، ومبسطة، مع نظام ألوان وتنضيد فاخر.
* **حسابات مالية دقيقة:** دعم الضرائب المخصصة (مثل 15%)، الخصومات المباشرة، وجداول الدفعات (Milestones)، وحسابات الإجماليات بصيغة ر.س (SAR).
* **تصدير وطباعة متطابقة:** زر طباعة مباشر ينتج وثيقة PDF نظيفة وعالية الدقة تتطابق تماماً مع ما تراه على الشاشة.

### 4. طور تدريب تفاعلي ممتع (Game-Quest Tutorial)
* شريط مهام تدريبي يوجهك خطوة بخطوة بالمهام الأربع الأساسية (طي الورق، دمج الأوراق، مستند التحديد، وإسقاط المجلدات) لضمان فهم كل الحركات السريعة بأسلوب تفاعلي.

## 🚀 البدء السريع

### المتطلبات الأساسية
* [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث)
* `npm` أو `pnpm` أو `yarn`

### التثبيت والتشغيل المحلي

```bash
# 1. استنساخ المستودع
git clone https://github.com/moody2071/pdf_creator.git
cd pdf_creator

# 2. تثبيت الحزم
npm install

# 3. تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على الرابط: `http://localhost:5173`

### فحص الكود وبناء الإنتاج

```bash
# فحص الأنواع وبناء ملفات الإنتاج المجمعة
npm run build

# معاينة حزمة الإنتاج محلياً
npm run preview
```

## 🏛️ الهندسة المعمارية (Architecture)

تم بناء التطبيق بهيكلية نظيفة تفصل تماماً بين منطق النطاق (Domain)، التخزين (Storage)، والواجهات (UI):

```
pdf_creator/
├── src/
│   ├── domain/               # المنطق الرياضي وحسابات الضرائب والقوالب وتجزئة الصفحات
│   │   ├── calculations.ts   # محرك الحسابات المالية الدقيقة ومنع الكسور العائمة
│   │   ├── pagination.ts     # خوارزمية تقسيم A4 التلقائي ومنع قطوع الجداول
│   │   ├── printable-html.ts # مولد HTML النقي للطباعة والتصدير
│   │   ├── quote.ts          # النماذج الأساسية لعروض الأسعار والمجلدات
│   │   └── templates.ts      # قوالب البداية الجاهزة وتوليد النسخ
│   ├── storage/              # طبقة التخزين المحلي والتعامل مع القرص
│   │   ├── workspace.ts      # إدارة ربط File System Access API و IndexedDB
│   │   ├── validation.ts     # التحقق البنيوي من سلامة ملفات JSON وترحيل المخطط
│   │   └── memory-fs.ts      # نظام ملفات وهمي في الذاكرة للاختبار والتوافق
│   └── ui/                   # المكونات والشاشات والتنسيقات
│       ├── components/       # بطاقات الأوراق، المجلدات، طور التدريب، ومستند التحديد
│       ├── screens/          # المكتبة، محرر العروض، مصمم القوالب، ومختار القالب
│       └── styles/           # نظام التنسيق النمطي (CSS Modules / Apple Look)
├── test/                     # بيانات مساحة عمل جاهزة للاختبار والمعاينة
└── vercel.json               # إعدادات النشر السحابي ورؤوس الكاش الفورية
```

## 🛡️ الخصوصية والأمان

* **صفر استدعاءات خارجية (Zero External Calls):** لا يتم إرسال أي محتوى أو بيانات مالية أو معلومات عملاء إلى أي خادم خارجي.
* **عدم تنفيذ شيفرات عشوائية:** القوالب والوثائق تُعرض بواسطة مكونات React نقية دون استخدام `eval` أو تشغيل نصوص برمجية خارجية غير موثوقة.
